# 未来的我 · AI 故事创想

幼儿园课堂职业体验的本地视觉与交互 Demo。老师操作电脑连接大屏，每次一位孩子体验。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开终端输出的本地地址，默认 http://127.0.0.1:5173/ 。`npm run build` 生成 `dist/`。

## 部署到 Vercel

将仓库导入 Vercel，构建命令为 `npm run build`，输出目录为 `dist`，安装命令为 `npm ci`（仓库已提供 `vercel.json`）。推送到已连接的 Git 分支后，Vercel 会自动构建预览或生产部署。构建依赖 Node.js 20.19+ 或 22.12+。

生产首页不加载姿态识别库；只有开启摄像头时才会下载 MediaPipe JavaScript 模块，随后仍需从 jsDelivr 获取 WASM、从 Google Storage 获取模型。部署站点通过 HTTPS 提供摄像头权限。

## 体验方式

1. 在主界面左侧直接选择九种职业之一，中央展示对应的 3D 人物与职业布景。
2. 在舞台下方选择挥手、展开双臂、左右摇摆、抬腿踏步或转身，预览角色动作。
3. 点击页面右上角的“开启摄像头”，站在画面中央，尽量让全身入镜。角色按镜子方式跟随，与真人预览中的左右方向一致：预览左侧的手对应角色左侧的手，侧摆和转身也同步镜像。摄像头中的脸会自动裁切为角色头像，无需上传图片。
4. “设置”保留骨架显示、角色视野、真人取景与缩放，以及切水果的老师参数。实时画面与角色并排显示，右上角 × 可关闭摄像头并恢复演示。
5. 真人窗口可在“广角完整”和 9:16 的“竖屏广角”之间切换，均保留全部源画面，可能留边。缩放仅调整显示比例，不扩大摄像头的物理视野。

主界面保留职业选择和互动舞台；手机竖屏把职业区收为横滑一行，手机横屏使用左侧窄职业栏，角色与真人始终并排；舞台按浏览器可用高度填充。任务面板、演示帮助、手动上传头像和形象侧栏已移除。视频与骨架共用镜像、缩放和显示比例。

## 当前边界

- 使用程序化制作的卡通 3D 身体、头型、服装和配饰，作为美术方向验证；不是最终精修角色。
- 示例脸部是手绘的成人卡通风格贴图，尚未接入儿童照片转未来成人头像的生成服务。
- 摄像头脸部贴图仅在本机裁切，不执行年龄变换、背景移除或 3D 重建。
- 头部只进行轻微装饰性转动与身体倾斜联动，没有独立人脸追踪；不支持自然侧脸、背身、眨眼或口型。
- 职业装扮用于验证模板扩展，职业专属玩法待制作。
- 摄像头使用 MediaPipe Pose Landmarker Lite 单人检测。通过估计的三维坐标映射肩、肘、腕、髋、膝和踝，支持原地抬腿、屈膝及最多约 ±60° 的身体侧转；头部反向补偿以减少平面脸贴图失真。不可见的腿部回到站姿，不支持可靠的背身跟踪、行走位移或专业动捕精度。
- 多人身份锁定、模型推理 Worker、儿童体型适配、设备性能验收尚未实现，不宜直接视为可交付的课堂成品。
- 摄像头推理在本机进行；初次加载需访问 jsDelivr 的 WASM 和 Google Storage 的模型。网络受限时可使用演示模式。网页字体也有外部加载，失败时使用系统字体。
- 本机 localhost 可调用摄像头，其他设备访问需 HTTPS。权限拒绝、摄像头不存在或模型加载失败会给出提示并保留演示模式。

产品规格见 [docs/PRD.md](docs/PRD.md)。

运行 `npm test` 验证关节映射与取景计算，`npm run build` 检查生产构建。

启动开发服务器后可打开 `/tests/fixtures/fruit-stage.html` 运行摄像头姿态的浏览器回归检查。该页面使用模拟姿态，不访问真实摄像头，覆盖单手入镜、双手入镜、举手开局、跟踪丢失/恢复和模式切换，检查切水果帧更新是否持续完成。

### 实时脸部贴图

摄像头成功启动后自动启用实时脸部贴图，利用姿态识别的眼、耳、鼻位置在本机裁切当前人物脸部，以约七帧/秒更新角色头部贴图。正面人脸不可用时保留上一次有效贴图；关闭摄像头恢复默认示例脸。此能力不进行身份验证、面部三维重建、卡通化或年龄生成，画面不上传和保存。

### 切水果 · 单人合作 Demo

点击舞台顶部的“切水果”模式按钮。在“设置”中选择 30 / 45 / 60 秒、慢速或轻快节奏、单手或双手，以及摄像头体感或老师鼠标演示。摄像头模式沿用角色手腕的实际屏幕投影绘制光点并判定切割；肩、肘、腕可见即可，无需腿部入镜。摄像头模式识别到双手手腕高于各自肩膀后立即开始正式回合；鼠标演示可完成练习或跳过，再经三秒倒计时开始。

无摄像头可点击“没有摄像头？老师演示”，按住鼠标或触屏拖动切水果；悬停不会切开。苹果、橙子、西瓜和草莓按每四颗包含四种的随机顺序出现，每颗均收集一个，漏切没有惩罚。目标为十二颗，达到后继续收集。回合开始后不再暂停：放下双手、跟踪丢失、关闭摄像头、打开设置或切到后台，均继续计算回合时间。手部不可用时不接受切割，水果照常下落。可点击“自由模式”退出当前回合。游戏模式锁定舞台旋转和缩放；取景或窗口改变只清除旧刀轨并重建投影。

结算后真人回合可明确“加入合作篮子”，同一回合只加入一次；演示回合不能加入。篮子仅保存在本页内存，刷新归零，也可在设置中清空。“下一位”清理检测历史、轨迹和旧头像，摄像头流继续复用，并重新等待新的人脸。返回自由体验会移除游戏实体。

游戏引擎、输入门槛、相对扫掠碰撞与篮子分别在 `src/fruit-game.js` 中，舞台呈现和老师操作在 `src/fruit-stage.js` 中。`npm test` 包含固定随机种子、扫掠与去重、停留/抖动/跳跃、跟踪中断、连续计时与后台到时结束、结算与篮子限制测试。

本次按 [切水果 Spec](docs/specs/fruit-slice-prd.md) 的单人 Demo 范围实现。没有可靠的多人控制者身份锁定，必须老师监督；尚未完成儿童试课、目标设备 30 FPS / P95 延迟实测、最终水果美术和舒适区现场调参，不代表课堂发布验收已完成。

新增“解放军军人”职业，归入“守护”分类，采用绿色制服、红星帽徽和“传递平安信号”任务；同样支持实时摄像头头像、体感跟随和切水果。

切割反馈采用局部切线高光、果肉与果籽截面、沿切线法向分开的两半、同色果汁溅射和命中位置的 +1。练习果显示“切开！”且不计数。切割声音使用单独裁出的约 130 毫秒短音，一次同方向的连续挥刀只触发一声，停顿超过约 180 毫秒或明显反向后可触发下一声；双手同时挥动合并为一声。一刀命中多个水果不追加音效，取消撕裂、果汁、低频和音阶叠加。音频未就绪时使用单段短合成声回退。背景音乐在举手开局、第一颗水果出现后淡入，等待开局及演示练习期间不播放，回合结束或退出时淡出；后台停止，返回仍在进行的回合后恢复。设置中的“音乐与音效”统一控制静音。特效遵循系统“减少动态效果”偏好。

摄像头切水果采用举手开局：双手手腕高于各自肩膀后立即出第一颗水果，跳过练习和确认按钮。举手只用于启动一次，开始后不再要求举手、稳定识别或点击继续；鼠标演示保留可选练习。后台计时按实际经过时间结算，返回时不补发水果或重放历史挥动。

摄像头启动时优先请求原生画幅（`resizeMode: none`），不再固定要求 16:9，减少浏览器为匹配比例而裁切。设备开放镜头变焦时自动请求其最低值，并通过实际设置确认；观察窗会显示成功、不支持或未确认状态。功能不可用时继续普通采集。不会自动切换到其他摄像头，最低变焦也不保证能启用独立超广角镜头；实际范围需在目标设备上验证。

### 职业氛围背景

九种职业拥有独立的 3D 布景：宇航员的火箭与行星、科学家的实验台与原子模型、消防员的消防车与车库、军人的营地与树林、医生的诊疗柜与心电屏、工程师的起重机与图纸、画家的画架与颜料、厨师的灶台与食材、园艺师的花台与温室。布景安排在人物两侧及后方，保留中央动作空间；舞台边框、标题随职业同步配色。环境动效保持轻微，尊重系统减少动态效果设置；切水果时固定环境动效。切换职业会释放上一场景的几何体和材质，避免道具叠加。

移动布局规则与验收记录见 [移动端并排体验布局](docs/specs/mobile-layout.md)。开发服务器下的 `/tests/fixtures/mobile-layout.html` 可预览带模拟真人的并排布局，不申请摄像头权限。
