# 未来的我 · AI 故事创想

幼儿园课堂职业体验的本地视觉与交互 Demo。老师操作电脑连接大屏，每次一位孩子体验。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开终端输出的本地地址，默认 http://127.0.0.1:5173/ 。`npm run build` 生成 `dist/`。

## 体验方式

1. 点击“职业与形象设置”，选择八个职业之一，准备头像后收起设置。02、03 面板默认不占用互动舞台。
2. 点击挥手、展开双臂、左右摇摆、抬腿踏步或转身看看，观察同一人物的动作。保持展开双臂约三秒可预览任务完成效果。
3. 点击骨架节点开关，观察角色节点与连线。演示节点是角色骨骼的可视化，不代表实时识别结果。
4. 上传准备好的正面卡通头像，图片将居中裁切并适配到脸部。可恢复默认示例。图片不会上传或持久保存。
5. 开启摄像头，站在画面中央，尽量让全身入镜。此时演示按钮停用，角色跟随真实识别；髋、膝、踝可见时启用腿部跟随。舞台右侧的大观察窗显示镜像视频与检测关键点，与左侧角色等分舞台，不需要向下滚动。
6. 使用舞台下方的视野滑杆调整 3D 画面缩放（60%–140%，默认 85%）。真人观察窗使用 9:16 竖向取景框，按舞台高度自动适配。摄像头仍优先采集 1280×720，以保留识别输入范围；横向源画面和骨架画布以完全相同的居中裁切、镜像方式显示，不旋转或拉伸画面。请适当后退，让全身和伸展的手臂进入竖框。裁切不会增加摄像头物理视野。

主界面按视口高度布局，设置独立放在弹窗内；窗口变化和开关摄像头会重新计算取景距离，但保留滑杆缩放值。骨架线使用深色描边、薄荷绿发光线、白色关节点和金色手腕点，支持脸部、手臂、躯干及可见腿部节点。髋部未入镜时仍显示可见上半身骨架。3D 角色显示 17 个骨架示意点，真人窗口最多显示 33 个实际检测点。

## 当前边界

- 使用程序化制作的卡通 3D 身体、头型、服装和配饰，作为美术方向验证；不是最终精修角色。
- 示例脸部是手绘的成人卡通风格贴图，尚未接入儿童照片转未来成人头像的生成服务。
- 上传功能只替换贴图，不执行年龄变换、背景移除、自动关键点对齐或 3D 重建。
- 头部只进行轻微装饰性转动与身体倾斜联动，没有独立人脸追踪；不支持自然侧脸、背身、眨眼或口型。
- 八个职业共用“展开双臂保持三秒”的任务机制。文案和装扮用于验证模板扩展，职业专属玩法待制作。
- 摄像头使用 MediaPipe Pose Landmarker Lite 单人检测。通过估计的三维坐标映射肩、肘、腕、髋、膝和踝，支持原地抬腿、屈膝及最多约 ±60° 的身体侧转；头部反向补偿以减少平面脸贴图失真。不可见的腿部回到站姿，不支持可靠的背身跟踪、行走位移或专业动捕精度。
- 多人身份锁定、模型推理 Worker、儿童体型适配、设备性能验收尚未实现，不宜直接视为可交付的课堂成品。
- 摄像头推理在本机进行；初次加载需访问 jsDelivr 的 WASM 和 Google Storage 的模型。网络受限时可使用演示模式。网页字体也有外部加载，失败时使用系统字体。
- 本机 localhost 可调用摄像头，其他设备访问需 HTTPS。权限拒绝、摄像头不存在或模型加载失败会给出提示并保留演示模式。
