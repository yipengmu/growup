# 移动端并排体验布局

## 目标与约束

电脑浏览器是主要使用场景，保留职业侧栏与角色/真人并排的框架。手机竖屏和横屏同样保持角色与真人并排；不强制旋转，不重开摄像头，不因旋转重启游戏回合。

## 设计参考

- [Active Arcade 官方介绍](https://www.activearcade.ai/)：以身体动作作为游戏输入，支持手机、平板与大屏。
- [Starri 官方介绍](https://www.starrigame.com/sc)：手机/平板放在面前进行体感节奏互动。
- [Starri 入镜指引](https://help.starrigame.com/hc/en-us/articles/10352130909203-I-can-t-start-the-game-It-s-stuck-on-the-Preparing-page-screen-mobile-version)：准备阶段确认头部、上半身在画面中央。

据此优先呈现互动内容与入镜反馈，压缩职业导航和重复文案；左右并排方式由本产品使用需求确定。

## 响应式规则

- 普通电脑布局保持原样。
- 宽度不超过 900 px，或宽度不超过 1100 px 且高度不超过 550 px，使用紧凑布局。
- 竖屏：职业区固定为约 58 px 的横向滚动选项；分类、英文和说明收起。舞台占剩余高度。
- 手机横屏：职业区变为 76 px 左侧窄栏，纵向滚动；舞台占其余宽度。
- 摄像头开启时，自由模式角色/真人宽度比例为 58/42；切水果为 60/40。
- 真人预览按实际采集比例完整显示，宽高同时限制在所属区域内；竖屏广角仍采用 9:16 外框。保留视频和骨架共同的镜像与缩放。
- 移动端仅保留模式、设置、摄像头与必要计分信息；操作按钮提供清晰的选中状态。

| 320 × 568 | 顶部 58 px 横滑条 | 374 px |
| 844 × 390 | 左侧 76 px 职业栏 | 284 px |
